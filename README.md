# CodeAlpha Network Sniffer

## Description
A Python-based network packet sniffer built using Scapy.

## Features
- Captures live network packets
- Displays source and destination IP addresses
- Detects TCP and UDP protocols
- Displays source and destination ports
- Extracts packet payload data
- Shows packet size and timestamps

## Technologies Used
- Python
- Scapy

## How to Run
1. Install Scapy:
pip install scapy

2. Run the script as administrator:
python sniffer.py
